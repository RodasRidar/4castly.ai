# UI/UX review (mock data, dark + light, 1024/1440/375 px)

## Fixed
- **Results screen, chat column**: the grid row was `auto`, so the chat grew with its content (2481 px) and the composer
  ended up at the very bottom of a long scrolling page. From `lg` the columns are now viewport-high panes (thread scrolls
  inside, composer pinned, results scroll on their own). Below `lg` the chat has a bounded height (`min(40rem, 75dvh)`).
- **Composer**: one rounded card with the send button inside (Claude Code Desktop style); focus ring on the card.

## Reviewed, no issues
Nuevo pronóstico, every conversation stage (reading, columns, calculating, locked, clarifications, confirmed, failed),
Historial, Perfil, Preferencias, Login, product detail, light theme.

## Open observations
- Mobile: results render above the chat, so the composer is far down the page; consider a sticky "Ask" entry point.
- Composer hint wraps to two lines in the narrow chat column; consider showing it only on focus.
- Results table scrolls inside the results pane (nested scroller); header is not sticky.
- Product detail mock: stock projection starts after the history ends (gap), likely fixture data.
- Not yet reviewed: Portafolio view, Parámetros drawer, export menu, dialogs, 404/error routes, tablet width.
